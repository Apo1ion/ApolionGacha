APOLION GACHA — 1.0.0

ЗАПУСК
Распакуйте весь архив в обычную папку и запустите ApolionGacha.exe.
Для Windows 10/11, 64 бита. Установка Python и других программ не нужна.
Интернет не используется. Не запускайте .exe прямо внутри ZIP-архива.
По умолчанию включены тёмная тема и иконка № 1.
Выбор темы и иконки сохраняется в source/interface.txt.

КНОПКИ
Карандаш — открыть папку data для редактирования файлов.
Двадцатигранник — крутка из всех включённых записей без фильтров.
При этом Мин., Сред., Макс. действуют, а отметки в панелях сохраняются.
Игральные кости — крутка с текущими фильтрами и параметрами редкости.
Дискета со стрелкой — копировать результат. Вставить: Ctrl+V.
Шестерёнка — тема, иконка и подробная справка.
Круговые стрелки — сброс отметок и поиска только в своей панели.
Стрелка назад — вернуться из настроек.

F5 — перечитать файлы вручную.
Пробел — крутка, если курсор не находится в поле ввода.
Ctrl+C — копировать результат, если фокус на основном окне.
Esc — вернуться из настроек. Page Up / Page Down — прокрутить справку.
Колёсико прокручивает список или результат под курсором.
Фиолетовую полосу прокрутки можно перетаскивать.

ФИЛЬТРЫ
Цикл нажатий: пусто → галочка → крестик → пусто.
При наличии галочек в панели разрешены только отмеченные ими варианты.
Без галочек разрешено всё, кроме исключённого крестиками.
Галочки внутри панели означают «любой из отмеченных».
Условия разных панелей применяются одновременно.
Крестик исключает соответствующий источник, фэндом или категорию.
Список фэндомов зависит от разрешённых источников. Скрытые отметки сохраняются.
Поиск только скрывает строки и не меняет фильтры крутки.
Сброс снимает также скрытые отметки.

В Шаблоне выбирается один вариант, без крестика.
Сброс или повторное нажатие снимает галочку, но сохраняет параметры.
Ручное изменение параметров также снимает галочку и не меняет файл шаблона.

ДОБАВЛЕНИЕ ЗАПИСЕЙ
Откройте файл нужной категории в Блокноте:
Предметы.txt, Способности.txt, Существа.txt, Особенности.txt, Навыки.txt.
Можно создать собственную категорию: новый .txt с таким же форматом.
Название файла становится названием категории. Шаблоны.txt — служебное имя.
Не храните инструкции и запасные копии .txt в папке data.
Для запасных копий используйте расширение .bak либо отдельную папку.

Скопируйте блок целиком и заполните его. У НОВОЙ записи оставьте Код: пустым.
Приложение присвоит и запишет уникальный код, предварительно сохранив прежний
файл в ИмяФайла.txt.bak. Существующие коды не меняйте.
При переносе записи между категориями сохраняйте её код.
При создании отдельной версии награды оставьте код пустым.

=== ЗАПИСЬ ===
Код:
Название: Название награды
Редкость: 2.5
Источник: Аниме
Фэндом: Название фэндома
Включено: Да
Описание:
Первая часть описания.

Следующий абзац.
=== КОНЕЦ ===

У записи ровно один источник, одна категория и один фэндом.
Для другого источника или фэндома создайте отдельную запись.
Старое имя поля «Фэндомы» читается для совместимости, но только с одним названием.
Авторским наградам можно указать Источник: Авторское и Фэндом: Авторский мир.
Обычным вещам — Источник: Реальный мир и Фэндом: Реальный мир.
Пишите одинаковые теги одинаково: Ван Пис и One Piece — разные теги.
Числовая редкость от 0.0 до 10.0, дробная часть через точку: 6.5.
Включено: Нет временно отключает награду, в том числе для полного рандома.
Для удаления уберите весь блок. Пустой файл категории допустим.
Не используйте служебные разделители отдельной строкой внутри описания.

Сохраняйте файлы в UTF-8, с BOM или без него.
Русские подписи полей обязательны. Порядок записей не влияет на шансы.
После сохранения изменения подхватываются примерно за две секунды либо при
возвращении в окно приложения. Также доступна клавиша F5.
При ошибке будут показаны файл, строка и причина; крутки приостановятся
до исправления, чтобы исключить выбор из неполного набора.

ШАБЛОНЫ
Редактируются только в data/Шаблоны.txt. Пример:

=== ШАБЛОН ===
Название: Мой шаблон
Мин: 1.0
Сред: 2.0
Макс: 4.0
=== КОНЕЦ ===

Название должно быть уникальным. Скопируйте блок для создания нового шаблона.
Для удаления уберите блок. Пустой файл шаблонов допустим.

ВЕРОЯТНОСТИ
Мин. и Макс. — строгие включительные границы.
Сред. — центр предпочтения, а не обещание точной средней редкости результатов.
Требуется: 0 ≤ Мин. ≤ Сред. ≤ Макс. ≤ 10.
Если числа равны, выпадают записи только с точно такой редкостью.
Вес награды = 4 ^ (−|редкость − Сред.|).
Шанс = вес награды / сумма весов всех подходящих наград.
Выбирается сама запись, без предварительного розыгрыша категории или фэндома.
При одинаковой редкости шансы отдельных записей одинаковы.
Больше подходящих записей фэндома — больше его суммарный шанс.
Повторы разрешены. Гаранта и обязательного чередования нет.
Показанный процент относится к условиям совершённой крутки.
Смена фильтров не меняет уже показанный результат и его процент.

РАНГИ
0.0–<1.0 — Мусорный
1.0–<2.0 — Обычный
2.0–<3.0 — Необычный
3.0–<4.0 — Редкий
4.0–<5.0 — Элитный
5.0–<6.0 — Эпический
6.0–<7.0 — Легендарный
7.0–<8.0 — Мифический
8.0–<9.0 — Божественный
9.0–10.0 — Трансцендентный
Ранг и цвет вычисляются по числу автоматически.

ИКОНКИ И ПЕРЕНОС
PNG on/off отображаются в настройках. ICO меняет значок окна приложения.
Значок самого .exe встроен и остаётся № 1.
Приложение не создаёт и не удаляет ярлыки автоматически.
Создайте ярлык вручную средствами Windows в удобном месте.
В настройках нажмите «Указать ярлык» и выберите этот файл .lnk.
Его значок обновится сразу и затем при выборе другой иконки в приложении.
Цель ярлыка должна указывать на ApolionGacha.exe именно из этой папки.
После перемещения ярлыка выберите его заново. Потерянный ярлык не пересоздаётся.
«Отвязать ярлык» убирает связь из настроек; сам файл ярлыка остаётся на месте.
Если перенесли приложение, исправьте путь в ярлыке либо создайте новый.
Закреплённые значки Windows могут потребовать открепления и повторного закрепления.
Переносите всю папку целиком. Для автокодов и настроек необходим доступ на
запись в папку приложения. Запуск от администратора не требуется.

ИСХОДНИКИ И ПРОВЕРКА
Папка source содержит настройки interface.txt, C++17-исходники, ресурсы и тесты.
Сохраняйте эту папку при переносе приложения.
build-windows.cmd — сборка в x64 Native Tools Command Prompt Visual Studio.
build-mingw.sh — сборка MinGW-w64 из Linux (запуск из папки source).
Код приложения написан заново под согласованные требования.
Названия рангов, цвета и начальные параметры шаблонов взяты из Chaos Gacha
автора Bronz / BronzDeck. Полная база оригинала не включена.
Дизайн и изображения предоставлены пользователем.

Исполняемый файл собран для Windows x64. Проверены алгоритмы, формат данных,
фильтры, границы редкости и вероятности. Проверены зависимости .exe:
только стандартные DLL Windows; сторонние среды выполнения не требуются.
Запуск графического окна на настоящей Windows в среде разработки не проверен.
